# Portugol Didático 📚

Este repositório foi criado para armazenar exercícios e algoritmos desenvolvidos durante os meus estudos de **Lógica de Programação**.

## 📝 Sobre o Projeto
O conteúdo aqui presente é estritamente **didático**. O objetivo é praticar os fundamentos da programação, como variáveis, tipos de dados e estruturas de decisão, utilizando a pseudolinguagem Portugol.

> **Nota:** Estes ficheiros não são programas executáveis (.exe), mas sim roteiros de lógica para serem lidos ou modificados para serem executados em interpretadores como o VisuAlg ou editores de texto.
